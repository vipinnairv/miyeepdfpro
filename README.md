# VIPINPDFSUITE

A client-side PDF suite with Adobe Acrobat-style tools. Everything runs entirely in the browser — no files are uploaded to a server.

## Features

- **Advanced Editor** — edit text directly in PDFs (with OCR for scanned pages), draw, highlight, and add text annotations
- **Merge** — combine multiple PDFs into one
- **Split** — split a PDF into individual pages
- **Organize** — reorder, rotate, or delete pages
- **Fill & Sign** — draw, type, or upload a signature/initials, place text/date/checkmarks, and fill in AcroForm fields
- **Watermark, Stamps & Page Numbers** — text/image watermarks, approval stamps (APPROVED, DRAFT, CONFIDENTIAL, etc.), page numbering, and custom headers/footers
- **Compress** — shrink file size by re-encoding pages as optimized images
- **Protect & Redact** — permanently black out sensitive content, or lock a PDF with an AES password

Built with [pdf.js](https://mozilla.github.io/pdf.js/), [pdf-lib](https://pdf-lib.js.org/), [jsPDF](https://github.com/parallax/jsPDF), [JSZip](https://stuk.github.io/jszip/), and [Tesseract.js](https://tesseract.projectnaptha.com/).
